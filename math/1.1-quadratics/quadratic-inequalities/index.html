Question 2 is two conditions joined by and, so both have to hold at once. Question 1 is a single condition. That difference is on purpose.

Do Now · what to keep from it

Two things to carry forward. One to leave behind.

  • Keep: multiply or divide an inequality by a negative and the sign flips. Question 2 needed it. That is why −2x ≥ −20 became x ≤ 10 and not x ≥ 10.
  • Keep: an answer can be a stretch of the number line, written as one statement. −5 < x ≤ 10 says "bigger than −5 and no more than 10" in a single line. You will write a lot of those today.
  • Leave behind: the idea that you get there by pushing symbols across. The flip rule is a rule about linear inequalities. It will not decide a quadratic one.

Direct instruction · 1 of 9

A quadratic inequality is not linear algebra with an extra term.

A linear expression like 2x − 4 climbs steadily. It is negative, hits zero once, and is positive after that. Two regions, one changeover. Push the symbols around and the inequality follows you.

A quadratic does not do that. x2 − 5x + 4 is positive, then negative, then positive again. Three regions, two changeovers. There is no single move that lands you on the answer.

So you are not solving for x. You are finding the changeover points, then deciding which regions you want.

Direct instruction · 2 of 9

The changeover points have a name: critical values.

A critical value is a value of x that makes the expression equal to zero. They are the roots of the matching equation, and they are the only places the sign can change.

x2 − 5x + 4 = 0  →  (x − 1)(x − 4) = 0  →  x = 1 or x = 4

Between 1 and 4 the curve is under the axis, so the expression is negative there. Outside them it is above the axis, so it is positive. Nothing changes sign anywhere else, because nowhere else does the curve touch zero.

Direct instruction · 3 of 9

First move, every single time: everything on one side.

Both routes below need the expression compared to zero. Critical values are the values that make it zero, so until one side is 0 there is nothing to find.

Move the terms across

5x ≥ x2 + 6
0 ≥ x2 − 5x + 6
x2 − 5x + 6 ≤ 0

Reading it from the other end turns the symbol around. "0 is greater than or equal to it" is the same claim as "it is less than or equal to 0".

Why not just divide?

x2 > 4x
divide by x  →  x > 4  wrong
x2 − 4x > 0  →  x(x − 4) > 0
x < 0 or x > 4

You do not know whether x is positive or negative, so you do not know whether to flip. Check x = −1: 1 > −4 is true, and dividing throws it away.

Route 1 · sign table on the number line

(x − 1)(x − 4) < 0

Critical values: x = 1 and x = 4. They cut the line into three regions. Take the sign of each bracket in each region.

Test one number per region: x = 0 gives +4, x = 2 gives −2, x = 5 gives +4. We want the product negative, so the middle column.

Route 2 · sketch it and read the axis

(x − 1)(x − 4) < 0

Same critical values, used as the two places the curve crosses the axis. The x2 term is +1, so it opens up.

We want the expression below zero, which is the part of the curve below the axis. That is the dip between the two crossings. Read the x values it sits over.

1 < x < 4

Strict on both ends. At x = 1 and x = 4 the expression is exactly 0, and 0 is not less than 0, so both crossings are out. That is what the hollow circles mean.

Direct instruction · 5 of 9

Every answer is one of two shapes: between, or outside.

Same inequality, same critical values. The only thing that changed is which way the curve opens, and the answer swapped shape.

Opens up (a > 0). Below zero is the dip in the middle, so < 0 and ≤ 0 give between. Above zero is the two arms, so > 0 and ≥ 0 give outside.

Opens down (a < 0). Everything swaps. The hump in the middle is now the part above zero, so > 0 and ≥ 0 give between, and < 0 and ≤ 0 give outside.

Write a between answer as one statement: 1 < x < 4. Write an outside answer as two, joined by "or": x ≤ 1 or x ≥ 4. An outside answer will not fit in a single chain. Writing 4 ≤ x ≤ 1 claims x is at least 4 and at most 1, which nothing is.

Route 2 · sketch

(k − 1)(k − 4) ≥ 0

Same curve. This time we want it on or above the axis, which is the two arms, and the crossings count because ≥ allows zero. Filled circles mean included.

k ≤ 1 or k ≥ 4

Perfect factoring gets this one wrong if you copied the shape of the last answer. The factors were identical. Only the direction of the symbol moved, and it moved the answer from the middle to the outside.

Direct instruction · 7 of 9

Which route, and why.

Both are correct and both earn full marks. They are not equally quick on every question, so here is the rule.

Default: sketch it

two brackets, and you can see the shape

Use it when:

  • The expression factors into two brackets.
  • The number in front of x2 is positive, so you know it opens up without thinking.
  • The equation has no real roots, so the curve never crosses. The table has nothing to fill in, the sketch answers it instantly.

About ten seconds, and it is the route Cambridge's own teaching guidance recommends.

Switch to: sign table

the picture is not obvious

Use it when:

  • The number in front of x2 is negative and you do not trust yourself to flip the picture in your head.
  • The brackets are awkward, like (5t − 3)(2t + 1), and the shape is not obvious at a glance.
  • You want the reasoning written down region by region, so an examiner can follow it.

It works from the factors alone. It never needs you to picture anything.

The one part that is not a choice sits before either of them: get everything on one side first. Skip that and both routes are wrong from the first line.

Direct instruction · 9 of 9 · back to Session 1

What if there are no critical values at all?

Run the discriminant on the matching equation. A negative discriminant means no real roots, so there are no critical values and the curve never touches the axis.

x2 + 2x + 5  →  Δ = b2 − 4ac = 22 − 4(1)(5) = 4 − 20 = −16

Δ < 0, and the x2 term is +1, so the curve opens up and sits entirely above the axis. The expression has one sign everywhere.

x2 + 2x + 5 > 0
true for every x
x2 + 2x + 5 < 0
true for no x

"No solution" is a complete answer here. So is "all real values of x". Neither one means you got stuck.
