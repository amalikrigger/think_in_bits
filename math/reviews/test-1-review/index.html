Reading the mark codes

M1 is a method mark: a correct method with the numbers put in, even with a slip. A1 is an accuracy mark for a correct answer, and it needs the M1 before it. B1 is a mark for a correct fact or value on its own. A *M1 with a later DM1 means the second method mark depends on the first. FT means follow through: you can still earn it using your own earlier answer.

Range on a restricted domain, and the inverse

Quiz 1 Q3 (71%). The fix is three values: both ends and the vertex.

The function f is defined by \(f(x) = x^2 - 6x + 11\) for \(0 \le x \le 5\).

(a) Express \(f(x)\) in the form \((x - p)^2 + q\). [2]

(b) Find the range of f. [2]

(c) Explain why f does not have an inverse. [1]

(d) The domain of f is changed to \(x \ge k\). Find the smallest value of \(k\) for which f has an inverse. [1]

(e) Using this value of \(k\), find an expression for \(f^{-1}(x)\) and state its domain. [2]

(a) half of \(-6\) is \(-3\): \(x^2 - 6x = (x - 3)^2 - 9\)\(f(x) = (x - 3)^2 - 9 + 11 = (x - 3)^2 + 2\)
(b) so the vertex is \((3, 2)\). Is \(x = 3\) inside \(0 \le x \le 5\)? Yes, so the lowest value is 2vertex: \(f(3) = 2\)
now the two ends: the curve rises away from the vertex both ways, so the highest value is at one of the ends\(f(0) = 11\),  \(f(5) = 25 - 30 + 11 = 6\)
the top is the bigger end, 11; the bottom is the vertex, 2. Write it in \(f(x)\), never \(x\)\(2 \le f(x) \le 11\)

Where did \(f(5) = 6\) go? It is a real output, but it is neither the top nor the bottom, so it is not in the answer. The end \(x = 0\) is farther from the vertex (3 across) than \(x = 5\) is (2 across), so it climbs higher.

(c) two different inputs give the same output, so f is not one-one\(f(2) = 3\) and \(f(4) = 3\): no inverse
(d) start the domain at the vertex, so the curve only goes up\(k = 3\)
(e) write \(y =\), swap \(x\) and \(y\), and solve for \(y\)\(x = (y - 3)^2 + 2\)  so  \((y - 3)^2 = x - 2\)
which root? On the domain \(x \ge 3\), f's inputs are at least 3, so the inverse's outputs must be at least 3. That needs the + root\(y - 3 = +\sqrt{x - 2}\)
the domain of \(f^{-1}\) is the range of f, which is now \(f(x) \ge 2\)\(f^{-1}(x) = 3 + \sqrt{x - 2}\),  \(x \ge 2\)

Two traps

Ends only. Working out \(f(0)\) and \(f(5)\) gives \(6 \le f(x) \le 11\), which misses the dip down to 2. Cambridge's examiner reports name this as the most common range error.

The wrong test. "It fails the vertical line test" is not a reason. That test checks whether something is a function. An inverse needs one-one, which is the horizontal line test: no horizontal line can cut the graph twice.

When does the order matter?

When both steps act in the same direction. In (a), the reflection and the translation both change \(y\), so swapping them changes the answer. In (b), the translation changes \(x\) and the stretch changes \(y\), so they do not interfere: stretching first gives the same \(y = 2x^2 + 16x + 30\).
